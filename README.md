## 🛠️ Quick Setup / Deployment Guide

1. Clone or download the repository to your local computer / server.
2. Upload the files to your web root folder (e.g., `public_html/` or `/var/www/html/`).
3. Ensure relative paths for files like `tools.html`, `font.html`, `pdf-to-word.html`, etc., remain intact.
4. Open `https://yourdomain.com/tools` in any browser.
